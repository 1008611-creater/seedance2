# Image2 Public Experience Rejection Audit

## Reset decision

- **Mode:** `targeted_evolution`.
- `/image2-cases` already has a coherent dark creator-workspace composition, a clear visual protagonist (real case imagery), and one dominant action (find and reuse a case).
- `/` uses a disconnected light editorial system, repeats equal-weight cards, and exposes broken remote images. It should adopt the case-library language rather than introduce a third visual system.
- Stable contracts: public URLs, login modal behavior, language toggle, real case data, case source attribution, and links to the case library/workbench/video studio.

## Scene contract

- **Outside condition:** AI creators collect attractive images but lose time reconstructing how the image was made.
- **Human action:** A creator opens a reliable case, reads its reusable prompt structure, saves it, and continues working.
- **Visual protagonist:** A compact, asymmetric collage of real Image2 cases with readable case labels.
- **Dominant action:** Open the case library.
- **Must be absent:** fake metrics, generic AI gradients, empty product mockups, decorative networks, broken image placeholders, and several equal primary CTAs.

## Reference translation

| Reference role | Decision |
| --- | --- |
| Primary reference | Project-owned `/image2-cases` runtime at 1440px and 390px. |
| Composition | Dark first screen, oversized Chinese product statement on the left, live case collage on the right, light operational content after the fold. |

## Three-screen storyboard

| Screen | Narrative job | Visual protagonist | Dominant action | Content proof | Desktop/mobile rule |
| --- | --- | --- | --- | --- | --- |
| 1 | Establish that Image2 turns good images into reusable prompt work | Four reliable case images | Open case library | Real case titles/categories and prompt-workflow promise | Desktop: split copy/collage; mobile: copy first, two-column collage below |
| 2 | Prove the library contains useful, traceable examples | Curated case editorial grid | Open a case | Image, category, bilingual title, compact prompt preview | Desktop: asymmetric grid; mobile: one-column cards with clamped copy |
| 3 | Explain the reuse path without a feature inventory | Two workflow lanes | Start with cases | Search/filter/deconstruct and save/adapt/continue | Desktop: two lanes; mobile: stacked, direct links |

## Rejection list

- Light homepage and dark case library reading as two unrelated products.
- Broken remote images or visible alt-text placeholders.
- Six equal cards with full raw prompt text.
- Generic hero followed by repeated feature sections.
- Fake social proof, fake activity, fake conversion counts, or unverified success rates.
- AI-purple gradients, abstract neural-network graphics, or decorative background imagery.
- Multiple equal primary CTAs, motion without a product job, scroll hijacking, custom cursors, particles, or autoplay video.
- Desktop composition merely stacked without mobile type/spacing/crop adjustments.

## Candidate acceptance

- Runtime evidence required at 1440px, 768px, 390px, and 320px.
- No visible failed image on the first two screens.
- Main CTA is visually dominant and keyboard reachable.
- Navigation, language, account modal, and case links remain functional.
- The page reads as the public entrance to the existing case-library product, not as a themed template.
