# Image2 下一阶段：提示词生产系统

- 交付时间：2026-10-06
- 适用渠道：McGrox / `gpt-image-2.5-sunburst`（质量优先）
- 定位：不是"一条好提示词"，而是**一台持续产出好提示词的机器**

---

## 一、为什么是"系统"而不是"一个提示词"

先看两种东西的差别：

| | 一条具体提示词 | 一套元提示词 |
|---|---|---|
| 产出 | 一张图 | 每次都能产出同等水准的图 |
| 复用 | 换产品就作废 | 换任何产品都成立 |
| 失败时 | 不知道错在哪一维 | 知道是哪一维没给值 |
| 积累 | 攒一堆用不上的句子 | 每次使用都在加固同一套判断 |

你要的是"杠杆高、一劳永逸"——那就是后者。一条"VR 头显爆炸结构海报"的提示词再漂亮，也只是**一次**；而一套能稳定拆解并重建任何案例的方法，是**每次**。

底层逻辑其实只有一句：**大多数人写提示词是在"描述画面"，而这套系统是在"指定控制维度"。**

描述画面 = 把结果交给模型的默认值，效果随机。
指定维度 = 每一维都显式给值，效果可复现。

---

## 二、核心：八维控制

这四个来源库里的高质量案例，拆开看都逃不出这八维。任何一个维度留空，就等于把那一维交给模型猜：

| 维度 | 必须显式回答 | 留空会怎样 |
|---|---|---|
| 1. 主体 | 是什么、数量、姿态、朝向、状态（新旧/干湿/开合） | 模型给你一个平庸的居中正视图 |
| 2. 构图 | 画幅比例、主体占比与位置、前中后景、视线引导 | 构图失去张力，四平八稳 |
| 3. 镜头 | 焦段、机位高度、景深、透视强度 | 变成"手机随手拍"的透视 |
| 4. 光线 | 光源性质（硬/软）、方向、色温、明暗比 | 均匀平光，最没有高级感的一种 |
| 5. 材质 | 表面质感（哑光/高光/织物/拉丝金属/玻璃折射） | 塑料感，是廉价感的主要来源 |
| 6. 配色 | 主色 + 辅色 + 点缀色，整体色调倾向 | 默认饱和，俗气 |
| 7. 文字排版 | 文字内容、字体性格、位置、与主体关系 | 乱码文字或该有字的地方没字 |
| 8. 约束 | 必须**保持不变**的部分 + 明确**不要**出现的东西 | 品牌标识漂移、参考图特征丢失 |

> 第 8 维是分水岭。负向约束（不要什么）往往比正向描述更能提升成片率——因为模型的默认倾向正是你要避开的那些东西。

## 三、主元提示词（可直接投喂）

以下整段可直接作为系统提示词使用：

```
你是顶级商业影像的提示词工程师。你的任务不是"描述一张图"，
而是把模糊意图翻译成一段能被 gpt-image-2.5-sunburst 精确执行、
且产出可直接商用的完整提示词。

【第一步：判定任务类型】
产品图 / 人物 / 海报排版 / 信息图 / 场景叙事 / 图像编辑。
不同类型的控制重点不同，先判定再动手。

【第二步：处理参考图】
若有输入图，先分两栏列出：
  A. 必须保持不变：主体形态、品牌标识、材质、比例、关键结构关系
  B. 允许改变：背景、光线、场景、配色、氛围
若没有参考图，必须明确指出：哪些特征只能靠文字约束，
以及"缺少参考图会损失什么"。不允许假装文字能替代参考图。

【第三步：逐维填充（八维，一个都不许留空）】
1 主体：是什么、数量、姿态、朝向、状态
2 构图：画幅比例、主体占比与位置、前中后景、视线引导
3 镜头：焦段、机位高度、景深、透视强度
4 光线：光源性质（硬/软）、方向、色温、明暗比、是否可见光源
5 材质：表面质感、微观细节、新旧痕迹
6 配色：主色 + 辅色 + 点缀色，整体色调倾向
7 文字排版：文字内容、字体性格、位置、与主体关系（无文字须显式声明）
8 约束：必须保持不变的部分 + 明确不要出现的东西

【第四步：注入张力（这是"极致效果"的来源）】
从下面挑 1—2 项，不要贪多：
- 时间切片：瞬间凝固（飞溅/碎裂/下坠中）或时间痕迹（拖影/水渍/磨损）
- 尺度反差：极大与极小同框，制造视觉冲击
- 非常规视角：贴地、俯冲、微距、镜面反射视角
- 材质冲突：柔软与坚硬、哑光与镜面、粗粝与细腻并置
- 叙事留白：画面里有"刚发生过什么"的痕迹

【输出格式】
1. 一段可直接复制投喂的完整提示词（按目标模型的语言习惯）
2. 变量清单：标出哪些词可替换（产品名/城市/品牌/色调），
   哪些是不可替换的结构关系
3. 参考图依赖说明：没有参考图会缺什么

【质量红线】
- 禁止"高质量""精美""4K""大师之作"这类空词——它们不产生任何控制力
- 禁止把互斥风格混写（如同时要求"写实照片"和"插画"）
- 物理必须自洽：光源方向与阴影一致，材质与光线匹配
- 宁可少写一维，也不要写一个自相矛盾的维度
- 不保守：在物理自洽的前提下，鼓励大胆构图与强对比
```

## 四、怎么用（三步，别多）

1. **在网站上找参照**：搜一个用途（如"电商主图"），打开 2—3 个高价值案例，看它们的**结构**而不是抄句子。
2. **把意图 + 参考案例结构丢给上面的元提示词**：得到八维填满的完整提示词 + 变量清单。
3. **只改变量，不动结构**：换产品、换城市、换品牌文字——这是它"一劳永逸"的地方。

---

## 五、验收标准（怎么知道这套东西生效了）

| 检查点 | 通过标准 |
|---|---|
| 维度完整性 | 产出的提示词八维都有显式值，没有"留白交给模型" |
| 可替换性 | 变量清单存在，且换掉变量后提示词仍然成立 |
| 参考图诚实度 | 明确说了缺参考图会损失什么，没有假装文字能替代 |
| 空词检查 | 通篇没有"高质量/精美/4K"这类不产生控制力的词 |
| 物理自洽 | 光线方向与阴影一致，材质与光源匹配 |
| 复现性 | 同一条提示词重跑，主要特征稳定，不随机漂移 |

---

## 六、与网站的关系

网站解决"**找到值得复用的结构**"（1569 条真实案例 + 四来源溯源 + 变量改写）。
这套系统解决"**把结构变成可投喂的提示词**"。

两者接起来才是完整闭环：**看图 → 拆结构 → 套八维 → 生成 → 只改变量 → 再次复用**。

缺了网站，你不知道好结构长什么样；缺了这套系统，你看着好案例也只能抄句子。
