# Seedance 2.0 周卡工作台原型

这是一个静态前端原型，用来验证“注册账号 -> 兑换卡密 -> 激活免费周卡 -> 每日 2 次 15s/720p Seedance 2.0 生成”的产品体验。

打开 `index.html` 即可体验。演示卡密：

```text
WEEK-SEED-2026
VIP-720P-7D
FREEWEEK
```

当前原型包含：

- 注册与卡密兑换界面
- 周卡状态、每日额度、权益规格
- 15s/720p 视频生成器操作台
- 队列进度模拟与成片库
- 移动端自适应布局

真实上线时需要接入后端鉴权、数据库、对象存储、视频生成队列和 Seedance 2.0 API。详细落地方案见 `ARCHITECTURE.md`。
